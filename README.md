# Accessibility Triage for Interactive Data Tools

**Work in progress**--accuracy is unverified at this time.

A tool for narrowing the WCAG success criteria relevant to interactive data tools. 
- A list of tool types preselects from a list of features. These features define what success criteria to pay attention to.
- A list of frameworks/tools generates a platform note--highlighting responsibility, gotchas, and accessibility notes.
- Focused on WCAG 2.1 AA and WCAG 2.2 AA.  

Pure HTML/javascript, just open index.html in the browser or serve as you like.

Made with the [OCELOTS data tools how-to forum](https://qubeshub.org/community/groups/ocelots/data-tools-how-to) in mind.

Try live at https://waisaed.github.io/data-tools-a11y/
